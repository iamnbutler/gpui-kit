This is not [`gpui-kit`](https://gpui-kit.com/). I don't know why `gpui-component` decided to rename to one character difference from `gpuikit` on Sept 3rd, 2026 - `gpuikit` has been around since [Oct 4, 2023](https://github.com/iamnbutler/gpuikit/commit/4dd3fd1a0570ac9127e6c517dd82e86d1edf12db) 😅

For the record, the name only ever moved *toward* `gpuikit`:

- **Oct 4, 2023** — born as `vitesse` ([`4dd3fd1`](https://github.com/iamnbutler/gpuikit/commit/4dd3fd1a0570ac9127e6c517dd82e86d1edf12db))
- **May 1, 2024** — renamed `vitesse` → `gpui-kit` ([`a51a441`](https://github.com/iamnbutler/gpuikit/commit/a51a441360ce20cce759f146b443fc126f092931))
- **by Nov 14, 2025** — hyphen dropped, `gpui-kit` → `gpuikit` ([`0997f05`](https://github.com/iamnbutler/gpuikit/commit/0997f0563439e13562013c30b1d2c9c81719c9f1))

So by the time `gpui-component` reached for `gpui-kit` in Sept 2026, this project had already worn that exact name and moved on from it.
